# Табличный датасет: Сравнительный анализ влияния ручного и искусственного обогащения данных

Репозиторий табличной части курсового проекта по теме:
> **«Сравнительный анализ влияния ручного и искусственного обогащения данных на качество и устойчивость обучения моделей машинного обучения»**

Предметная область: **Музыкальная аналитика (Spotify Audio Features)**  
Целевая задача: **Бинарная классификация популярности трека (`is_popular`: 0 vs 1)**

## Описание базового датасета (`data/raw/base_spotify_2000.csv`)

* **Источник:** Hugging Face `maharshipandya/spotify-tracks-dataset` (зеркало Kaggle).
* **Лицензия:** **BSD License / Open Data**.
* **Размер выборки:** $2\,000$ строк, строго сбалансированных по классам (1 000 класса 0 и 1 000 класса 1).
* **Целевая колонка:** `is_popular` (`1` — популярный радио-хит, `0` — нишевый/лоу-фай трек).
* **Числовые признаки (8 фичей):**
  1. `danceability` (танцевальность, $0.0 \dots 1.0$)
  2. `energy` (энергичность звучания, $0.0 \dots 1.0$)
  3. `loudness` (громкость в dB, $-45.0 \dots 0.0$)
  4. `speechiness` (речевая составляющая, $0.0 \dots 1.0$)
  5. `acousticness` (акустичность, $0.0 \dots 1.0$)
  6. `valence` (музыкальная позитивность, $0.0 \dots 1.0$)
  7. `tempo` (темп в BPM, $50.0 \dots 220.0$)
  8. `duration_ms` (длительность в миллисекундах)
* **Информационные поля:** `track_name` (название трека), `artists` (исполнитель).
